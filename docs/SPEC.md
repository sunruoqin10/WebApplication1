> 版本：V1.0

---

## 一、项目概述

### 1.1 项目背景

基于现有的 ASP.NET Web Forms 项目（.NET 4.7.2）进行功能扩展，构建一个支持通用审批流程的 OA 系统。用户可通过可视化的表单设计器和审批链配置器，快速创建各类审批流程。

### 1.2 项目定位

**审批流程系统**：侧重于各种审批流程的自动化管理，支持表单自定义、审批链灵活配置。

### 1.3 核心目标

- 提供通用审批能力，支持可配置的表单设计和审批流程
- 预置常用审批模板（请假、报销），快速投入使用
- 实现多级审批机制，支持固定指派和按角色匹配审批人
- 提供完整的系统管理和日志审计功能

## 六、工作流流转规则

### 6.1 流程发起

1. 用户选择流程模板
2. 填写表单数据（必填项校验）
3. 提交申请
4. 系统根据审批链配置生成审批任务
5. 第一级审批人收到站内通知
6. 申请人可在"我的申请"中查看进度

### 6.2 审批执行

1. 审批人登录系统，看到待办数量红点
2. 进入"待我审批"列表
3. 点击查看申请详情和表单内容
4. 选择通过或驳回（可填写意见）
5. 系统更新审批状态，生成历史记录
6. 如果通过，流转到下一级；如果驳回，流程结束

### 6.3 多级审批规则

```
示例：3级审批链
├── 第1级：部门经理审批（按角色匹配）
├── 第2级：总经理审批（固定指派）
└── 第3级：HR审批（按角色匹配）

流程说明：
1. 申请人提交 → 生成3个审批任务
2. 第1级审批 → 通过后第2级可审批
3. 第2级审批 → 通过后第3级可审批
4. 第3级审批 → 通过后实例状态变为"approved"
5. 任一级驳回 → 实例状态变为"rejected"，流程结束
```

### 6.4 审批人匹配规则

| 匹配类型 | 规则说明 |
|----------|----------|
| 固定指派 | 指定具体用户审批（模板配置时选择） |
| 按角色匹配 | 审批时查询申请人所在部门的指定角色用户 |
| 上级审批 | 审批时查询申请人的上级部门负责人 |

## 七、通知机制

### 7.1 通知触发场景

| 场景 | 通知类型 | 接收人 |
|------|----------|--------|
| 新申请待审批 | approval_pending | 当前节点审批人 |
| 申请被通过 | approval_result | 申请人 |
| 申请被驳回 | approval_result | 申请人 |
| 审批通过（多级） | approval_pending | 下一级审批人 |

### 7.2 通知展示

- 页面右上角显示通知图标和未读数量红点
- 点击跳转到通知列表
- 点击单条通知跳转到相关审批/申请详情

## 八、非功能性需求

### 8.1 性能要求

- 页面响应时间 < 2秒
- 数据库查询避免 N+1 问题
- 大数据量列表使用分页

### 8.2 安全要求

- 密码使用 SHA256 加密存储
- SQL 注入防护（使用参数化查询）
- Session 超时验证
- 敏感操作记录日志

### 8.3 可维护性

- 分层架构（DAL/ BLL / Pages）
- 代码注释清晰
- 统一的错误处理
